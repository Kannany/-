# 📊 توثيق وتحليل العنف الجنسي المرتبط بالنزاع في السودان

## 🎯 الهدف من المشروع
توثيق وتحليل الانتهاكات الجسيمة المرتكبة ضد النساء والفتيات في السودان، والإجابة على السؤال: **هل هي تجاوزات فردية أم انتهاكات ممنهجة؟**

## 📊 المصادر المعتمدة
- تقارير الأمم المتحدة (OHCHR)
- منظمة العفو الدولية (Amnesty International)
- أطباء بلا حدود (MSF)
